## Независимый математический расчёт

Рабочая семантика использует Fraction и арифметические определения.
`tests/reference.py` использует буквальные матрицы над целыми 0,1,2,
которые обозначают удвоенные значения. Этот модуль не импортирует
рабочие дерево, парсер и вычислитель.

Сравнены все 122 оценки пяти формул и 5084 оценки четырёх отношений:
всего 5206. Для каждого отношения сверены все значения посылок и
заключения, а не только общий флаг. Отдельные тесты проверяют ожидаемые
свойства, явные свидетели, исходную r→s в R3 и CSV.

## Проверка отчёта

DOCX создан из результатов и протоколов только после успешных тестов.
Использованы редактируемые формулы OMML, включая индексы импликаций
и степени в оценке сложности. PDF экспортирован Microsoft Word.
Просмотрены изображения всех девяти страниц окончательного экспорта:
нет обрезанных формул, наложений, потерянных строк и разрывов таблиц.
Данные таблиц дополнительно сопоставлены с JSON/CSV.

Стандартный `render_docx.py` не смог выполнить преобразование:
`FileNotFoundError: LibreOffice soffice.exe was not found on PATH`.
После диагностики использован имеющийся Word и Poppler. Это ограничение
конкретного рендерера, а не непройденная проверка PDF. При растеризации
Poppler сообщил о резервных шрифтах Symbol/ArialUnicode; просмотр всех
страниц подтвердил наличие используемых символов. Переносимость через
LibreOffice не проверялась.

SHA-256 готовых документов и итог визуальной/структурной проверки записаны
в `evidence/report_validation.json`. Итог упаковки окончательного ZIP
создаётся после её выполнения в `output/packaging_verification.json`.
`tools/package_submission.py` проверяет CRC, все хеши в ZIP и после
извлечения, запускает 58 тестов, расчёт варианта и интерактивный пример
из извлечённой папки с пробелами и кириллицей в пути. Протокол упаковки
хранится рядом с ZIP: хеш самого ZIP нельзя включить в этот же ZIP.

## Сохранность ЛР1 и ограничения

Все 545 прежних файлов перенесены с совпадением SHA-256; сохранены оба
прежних каталога-копии, оригинальные документы и материалы.
После переноса из `lab1` выполнены `py -3.12 -m unittest discover -s tests -q`
(60 тестов, OK) и `py -3.12 lab1.py --demo` (7 из 7 приняты).
Контроль переноса — `evidence/reorganization_verified.json`.

Проверки не являются доказательством отсутствия всех программных ошибок.
Другой физический компьютер, Linux/macOS, Python 3.10/3.11/3.13 отдельно
не проверялись. Заявленная минимальная версия 3.10 опирается на используемый
синтаксис и API стандартной библиотеки. Сложность полного перебора
экспоненциальная; лимит 6561 строки явный и диагностируется. Зависимостей
на ЛР1, сеть, Word или сторонние Python-пакеты у приложения нет.
