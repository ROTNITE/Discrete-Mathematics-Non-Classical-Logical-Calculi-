# План выполнения ЛР2

Основание: предоставленное задание ЛР2, страницы 1–4, вариант 3.

1. Прочитать все 27 учебных файлов, включая формулы в изображениях,
   заметки презентаций и все фотографии. Сохранить состав и SHA-256.
2. Разнести работы по `lab1` и `lab2`, общие материалы — в `materials`.
   Сохранить старые копии, проверить SHA-256 каждого перенесённого файла.
3. Создать самостоятельное консольное приложение на Python 3.10+ без
   внешних зависимостей. Сохранить подход ЛР1: неизменяемое дерево,
   рекурсивный спуск, диагностика позиции, отдельные логика и интерфейс.
4. Добавить конъюнкцию и отдельный узел импликации; не раскрывать её
   через дизъюнкцию, поскольку в L3 это другая операция.
5. Реализовать точные значения 0, 1/2, 1, полный перебор, свойства,
   контрпримеры, следование с выделенным значением 1 и сравнение систем
   на общих допустимых оценках.
6. Ввести пять формул и четыре отношения варианта 3 буквально по PDF.
   В R3 сохранить посылку r→s; не заменять её предположением q→s.
7. Проверить таблицы операций по явным матрицам и весь вариант независимыми
   функциями, отдельно проверить ошибки ввода и оба сценария интерфейса.
8. Сформировать полные CSV, JSON, разбор результатов, отчёт DOCX/PDF,
   памятку к защите и переносимый ZIP. Проверить отрисовку всех страниц,
   архив и запуск извлечённой копии.

Принятые соглашения: однобуквенные латинские переменные, как в методичке
ЛР1; приоритет ¬, ∧, ∨, →; бинарные операции группируются слева, как на
слайде 16 лекции 1. Другую группировку задают скобки. Константы в язык
ЛР2 не добавляются. Только 1 считается выделенным значением.
