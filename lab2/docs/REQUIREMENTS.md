# Соответствие заданию ЛР2

Источник требований: `materials/Лабораторная работа 2.pdf`, страницы 1–4.
Выбран вариант 3 по выполненной ЛР1. Страница 5 также изучена.

| Требование | Реализация | Проверка |
|---|---|---|
| Разрешённый язык | Python 3.10+, стандартная библиотека | Проверки на доступных Python 3.12 и 3.14 |
| Синтаксическая корректность | `formula.tokenize`, `Parser`, `FormulaError` | Все примеры методички, ошибки, Unicode, позиции, пределы |
| Внутреннее представление | Неизменяемые Var, Not, Binary | Структура всех операций и обратимость печати |
| ¬,∧,∨,→ и скобки | Приоритеты и левая группировка из материалов | `test_formula.py` |
| Три системы с собственными областями | CLASSIC, K3, L3, точные Fraction | Явные матрицы всех допустимых ячеек операций |
| Заданная оценка | `evaluate`, команда `eval`, пункт меню 1 | Пример p=q=1/2 и ошибки области classic |
| Полный перебор | Декартово произведение по различным переменным | Число строк 2^n/3^n, уникальность строк, предел |
| Таблица истинности | Команда `table`, CSV варианта | Совпадение каждой строки с независимым расчётом |
| Общезначимость и выполнимость | `FormulaAnalysis.as_dict` | Все пять формул, свидетели и распределения |
| Невыполнимость отдельно от тождественной ложности | Два разных поля и сообщения | F3 в K3/L3: нет единиц, есть 1/2 |
| Контрпример к общезначимости | Первая оценка с F≠1 | F1 при p=1/2 |
| Семантическое следование | `entails` по объединению переменных | Все четыре отношения во всех системах |
| Контрпример к следованию | Все Ai=1 и B≠1 | R2 L3, R3, R4, отдельный случай B=1/2 |
| Нет совместных моделей | `vacuous`, отдельное сообщение | Посылки p и ¬p во всех логиках |
| Сравнение значений и свойств | Команда `compare`, попарные пересечения областей | K3/L3 при 1/2 и classic с недопустимыми строками |
| Проверка заданного варианта | FORMULAS, RELATIONS, `variant` | 122 оценки формул, 5084 оценки отношений; независимые матрицы |
| Отчёт с результатами | DOCX/PDF, RESULTS.md, JSON, 27 CSV | Отрисовка, проверка данных, CRC и SHA-256 ZIP |

Для каждой формулы возвращается модель при её наличии и контрпример при
нарушении общезначимости. Для каждого отношения возвращаются число моделей,
число контрпримеров и значения всех посылок/заключения в свидетеле.

Реализация ЛР2 самостоятельна: ей не требуется импортировать соседнюю ЛР1.
Сохранены подход к дереву, соглашения об именах, скобках и группировке.
Изменение дерева импликации необходимо для корректной семантики L3.
