В classic закон исключённого третьего общезначим. В K3/L3 при p=1/2 оба дизъюнкта равны 1/2, поэтому результат 1/2. При p=0 или p=1 результат 1, так что формула выполнима во всех системах.

| 0 | 1 | 1 | 1 |

### F5

### R1

`(p ∨ q), (p → r), (q → s), ((r ∨ s) → t), (t → u) ⊨ u`

Если max(p,q)=1, то p=1 или q=1. В первом случае из p→r=1 получаем r=1, во втором из q→s=1 получаем s=1. Следовательно, r∨s=1, затем t=1 и u=1. Использовано свойство 1→b=b, общее для всех трёх систем. Поэтому R1 выполняется везде.


Полные таблицы: `tables/R1_classic.csv`, `tables/R1_k3.csv`, `tables/R1_l3.csv`.

### R2

`(p → q), (q → (r ∨ s)), (r → t), (s → t), (t → u) ⊨ (¬p ∨ u)`

В classic/K3 при p=0 заключение ¬p∨u равно 1. При p>0 посылка p→q=1 в K3 требует q=1. Далее q→(r∨s)=1 даёт r∨s=1; хотя бы одна из r,s равна 1, откуда t=u=1. В L3 условие a→b=1 означает только a≤b. Посылки обеспечивают цепочку p≤q≤max(r,s)≤t≤u, но при промежуточных значениях max(1−p,u) может быть 1/2. Например, p=q=s=t=u=1/2,r=0: все посылки равны 1, заключение равно 1/2.

- l3: p=1/2, q=1/2, r=0, s=1/2, t=1/2, u=1/2; посылки 1, 1, 1, 1, 1; B=1/2.

Полные таблицы: `tables/R2_classic.csv`, `tables/R2_k3.csv`, `tables/R2_l3.csv`.

### R3

`(p ∨ q), (p → s), (r → s), (s → t), (t → u) ⊨ (u ∧ ((p → q) ∨ (q → p)))`

Третья посылка в PDF записана r→s. Переменная q не обязана передавать истину по цепочке к u. При p=0,q=1,r=s=t=u=0 дизъюнкция p∨q равна 1, четыре импликации тоже равны 1, но u=0 и заключение равно 0. Этот двузначный контрпример допустим во всех трёх системах. Вариант проверен буквально, без замены r→s на q→s.

- classic: p=0, q=1, r=0, s=0, t=0, u=0; посылки 1, 1, 1, 1, 1; B=0.
- k3: p=0, q=1, r=0, s=0, t=0, u=0; посылки 1, 1, 1, 1, 1; B=0.
- l3: p=0, q=1, r=0, s=0, t=0, u=0; посылки 1, 1, 1, 1, 1; B=0.

Полные таблицы: `tables/R3_classic.csv`, `tables/R3_k3.csv`, `tables/R3_l3.csv`.

### R4

`(p ∨ q), (p → r), (q → s), (r → t), (s → t) ⊨ (p → q)`

Посылки связывают p и q с общим следствием t, но не устанавливают p→q. При p=r=t=1,q=s=0 все пять посылок равны 1, а p→q=0. Поэтому отношение ложно во всех системах. Общность следствия не позволяет обратить направление импликаций.

- classic: p=1, q=0, r=1, s=0, t=1; посылки 1, 1, 1, 1, 1; B=0.
- k3: p=1, q=0, r=1, s=0, t=1; посылки 1, 1, 1, 1, 1; B=0.
- l3: p=1, q=0, r=1, s=0, t=1; посылки 1, 1, 1, 1, 1; B=0.

Полные таблицы: `tables/R4_classic.csv`, `tables/R4_k3.csv`, `tables/R4_l3.csv`.

Ни в одном из 12 случаев посылки не оказались совместно невыполнимыми.
