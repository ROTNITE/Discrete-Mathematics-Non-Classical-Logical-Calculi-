# Соответствие заданию

Выбран вариант 3. Перечень составлен после чтения задания, методички,
обеих лекций и всех семинарских материалов.

| Требование | Реализация | Проверка |
|---|---|---|
| Разрешенный язык и минимальный интерфейс | Python 3.10+, консоль | Запуск на Python 3.12.14 и 3.14.3 |
| Проверка п.п.ф. | tokenize, Parser, FormulaError | test_formula.py, примеры страницы 1 методички |
| Абстрактное синтаксическое дерево | Var, Not, Or | Проверка формы дерева, обратный разбор печати |
| Лишние парные скобки отбрасываются | Скобки управляют разбором, отдельного узла нет | test_redundant_parentheses_from_method |
| Однобуквенные переменные | Один токен на букву, соседние токены отвергаются | mn, p p, p1, математический Unicode |
| Базис ¬,∨ | Imp раскрывается в Or(Not(A), B) | test_implication_expansion |
| Аксиомы именно варианта 3 | AXIOM_TEXTS, AXIOMS, семь схем, match_schema | Экземпляры всех семи схем, одинаковые повторные параметры |
| Список правил и текущего доказательства | RULES, Session, Step, Reason, Reference | Сеансы независимы, ссылки только назад |
| Сравнение по структуре | Неизменяемые dataclass и match_substitution | Неравенство переставленных и иначе сгруппированных деревьев |
| MP с сообщением и добавлением результата | Session._reason, Session._message, Session.submit | MP с аксиомами и с предыдущими строками |
| β с формулой, переменной и источником | match_substitution, Reason | Равномерность всех вхождений, составная вставка |
| Одна переменная за шаг β | Перебор одной переменной источника | Отказ двум заменам в производной формуле, принятие после промежуточной строки |
| Уточнение преподавателя об экземплярах | Прямое совпадение со схемой до MP и β | A1: a→(a∨b); A6: (¬¬¬q→¬q)→(q→¬¬q) |
| Отказ неправильному выражению | FormulaError, Verdict(False) | Не меняются строки и индексы доступных формул |
| Обработка ошибок | Диагностика позиции, размера, UTF-8 и файлов | CLI, лимиты, недостающий файл, поврежденная кодировка |

Подробности допущений: импликация A⊃B := ¬A∨B; A7 — левая формула
пункта 7; нет специальных констант. Эти конвенции отражены в программе,
отчете, README и MATERIALS_REVIEW.md. Никакие требования других вариантов
не подменяют выбранный вариант 3.
