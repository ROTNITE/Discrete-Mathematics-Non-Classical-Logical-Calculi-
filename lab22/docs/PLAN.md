# План выполнения ЛР 1

Вариант 3 подтвержден пользователем 19 октября 2026 года.

1. До реализации прочитать все 26 исходных файлов: 45 слайдов лекций,
   13 слайдов семинара, 5 страниц PDF, 5 PNG и 16 фотографий.
   Зафиксировать содержание, ограничения читаемости и расхождения источников.
2. Реализовать на Python 3.10+ консольный верификатор. Внешние зависимости
   для запуска и тестов не нужны. Дерево содержит только переменные, ¬ и ∨.
   Импликация является сокращением ¬A ∨ B. Импликации без скобок
   группируются слева, как в лекции 1, слайд 16.
3. Хранить семь схем аксиом варианта 3 и принятые строки доказательства.
   По уточнению преподавателя распознавать экземпляры схем с несколькими
   согласованными подстановками напрямую; отдельно проверять повтор, MP
   и одну равномерную подстановку β из ранее доказанной формулы.
   Ошибочные строки не меняют состояние. Для каждой принятой строки хранить
   проверяемое обоснование и ссылки на источники.
4. Проверить примеры методички, все аксиомы варианта 3, положительные и
   отрицательные случаи β и MP, состояние сеанса, Unicode, пакетный и
   интерактивный запуск, ограничения размера. Семантику использовать только
   в независимых тестах корректности аксиом, не для принятия строк.
5. Подготовить отчет DOCX и PDF, разбор материалов, инструкции и сценарий
   защиты. Выполнить программу и тесты, сохранить реальные протоколы,
   проверить верстку отчета и содержимое итогового ZIP.

Исходные материалы сохраняются без изменений. Проект до начала работы
содержал только учебные материалы и пустой Git-репозиторий без кода,
конфигурации сборки и существующих тестов.
